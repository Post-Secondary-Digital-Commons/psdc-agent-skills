# Glossary

## Assessment

A bounded evaluation of named artifacts at an identified revision against a
declared rubric. An assessment reports evidence; it does not grant authority.

## Evidence state

One rung in the PSDC readiness ladder: proposed, documented, contracted,
structurally validated, implemented, deployed, or production proven.

## Skill policy

The machine-readable record that says which skill is enabled for which lifecycle
phase, where it came from, and which PSDC guardrails apply.

## Workspace command center

A generated projection of repository, decision, contract, test, and evidence
records. It is a navigation and situational-awareness surface, not an authority.
