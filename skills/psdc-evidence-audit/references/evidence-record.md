# Evidence Record Fields

- `claimId`: stable identifier.
- `claim`: exact bounded statement.
- `scope`: common PSDC, named institution, or both.
- `state`: evidence-ladder state asserted.
- `artifact`: path or immutable URL.
- `revision`: commit, digest, or version.
- `producer`: human, tool, or agent that produced it.
- `verification`: command or review method and result.
- `observedAt`: timestamp of verification.
- `expiresAt`: when the evidence must be refreshed, or null for immutable facts.
- `limitations`: what the artifact does not establish.
